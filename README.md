# 理科ラボ 5

小学5年生理科を、条件を動かしてすぐ結果を確かめるシミュレーターと、「知識・実験準備・考察」の問題学習で学ぶ、ブラウザ完結型の教材です。植物、メダカ・人、天気、流れる水、物のとけ方、電磁石、ふりこの7単元を収録しています。

## 特徴

- タブレットで押しやすいレスポンシブUI
- 「シミュレーション」「問題を解く」の2つの入口を用意
- 7単元の条件操作型シミュレーター（図・結果が操作に合わせて即時更新）
- 横画面では主要な図・操作・結果を1画面に集約
- 問題学習側には、条件カード・観察項目・考察問題を従来どおり収録
- LAB側は自由記述や実験ノートを要求せず、操作直後に短い結果を表示
- 進捗、初回正解、間違えた条件カードを `localStorage` に保存
- 外部API、APIキー、サーバー、データベース、外部フォント不使用
- GitHub Pagesでそのまま公開可能

## 公開方法

リポジトリ直下にこのフォルダ内のファイルを置き、GitHubの Settings → Pages で `main` ブランチのルートを公開元に設定します。ビルド処理は不要です。

## 次の単元を追加する方法

1. 単元データファイルを追加する。
2. `index.html` でそのファイルを `app.js` より先に読み込む。
3. `catalog.js` に単元カードを追加する。
4. `labs/index.js` に現行単元IDのマニフェストを追加し、対応する `labs/*-lab.js` に初期条件、操作、図、結果を追加する。
5. 問題学習のデータを `knowledge / preparation / consideration` の3区分で登録する。

問題学習の共通ロジックは `app.js`、LABの共通ロジックは `labs/lab-core.js` にまとめています。既存の問題データ・答え合わせ・進捗保存を残したまま、単元別LABだけを独立して拡張できます。

## 教材内容の基準

- 文部科学省「小学校学習指導要領（平成29年告示）解説 理科編」
- 文部科学省「小学校理科の観察、実験の手引き」第5学年各内容
- 国立教育政策研究所「令和7年度 全国学力・学習状況調査 小学校理科 解説資料」

条件制御では、調べたい要因だけを変え、それ以外をそろえる考え方を全単元の共通パターンにしています。全7単元で、知識21題、実験・観察準備23題、考察35題を収録しています。
