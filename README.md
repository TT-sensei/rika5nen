# 理科ラボ 5

小学5年生理科を、条件を変えてすぐ結果を確かめるシミュレーションと、問題学習で学ぶブラウザ教材です。植物、メダカ・人、天気、流れる水、物のとけ方、電磁石、ふりこの全7単元を収録しています。

## この教材の考え方

5年生では、「調べたい条件だけを変え、ほかの条件をそろえて比べる」ことを大切にします。

- **シミュレーション**：条件を動かす → 図と数値が変わる → 短い結果を確かめる
- **問題を解く**：知識を整理する → 実験方法を考える → 結果を根拠に説明する

シミュレーションは、自由記述や長い実験ノートを前提にしていません。スライダー、選択ボタン、プリセット、リセット、時間を進める操作を使い、気になる条件を何度でも試せます。

## 収録単元とシミュレーション

| 単元 | LABで試すこと |
|---|---|
| 植物の発芽と成長 | 水・空気・温度・日光・経過日数を変え、発芽と成長をくらべる。花から実になる変化も見る |
| メダカ・人のたんじょう | メダカの卵の経過日数と観察倍率を変え、受精卵から稚魚までの変化を見る |
| 天気の変化 | 雲の動き、風向き、観察地点、経過時間、天気図の表示を変える |
| 流れる水のはたらき | 水の速さ・傾き・水量・運ぶ土砂を変え、けずる・運ぶ・たい積する変化を見る |
| 物のとけ方 | 物質、水の量、温度、時間、かき混ぜ方などを変え、とける速さや量をくらべる |
| 電流がつくる磁力 | 電池、電流、コイルの巻き数、鉄心、スイッチを変え、電磁石の強さをくらべる |
| ふりこの運動 | ふりこの長さ、おもりの重さ、振れ幅、測る回数を変え、1往復の時間をくらべる |

## 問題学習と学習記録

問題学習は、単元ごとに次の3段階で進みます。

1. 知識
2. 実験・観察の準備
3. 考察

実験・観察の準備では、「変える条件」「そろえる条件」「記録すること」などを整理します。考察では、表やグラフなどの結果を見て、言えることと言えないことを区別します。

単元のクリア状況、正解状況、条件カードの間違いは、利用中のブラウザ内に保存されます。学習記録画面では、単元のスタンプと、見直したい条件カードを確認できます。

## 主な機能

- タブレットで操作しやすいレスポンシブUI
- ホーム画面を「シミュレーション」と「問題を解く」の2つの入口に分けた構成
- 7単元の条件操作型LAB
- 操作に合わせて図・数値・結果を即時更新
- 横画面では、主要な図・操作・結果を一つの作業画面にまとめる設計
- LABは、選んだ単元に必要なシミュレーションだけを読み込む構成
- 研究ランク、発見図鑑、コレクションバッジ
- 外部API、APIキー、サーバー、データベース、外部フォントを使用しない構成
- GitHub Pagesでそのまま公開可能

## ファイル構成と読み込み

~~~text
rika5nen/
├── index.html
├── styles.css
├── app.js                   # 現在のGitHub Pages用エントリ
├── catalog.js               # 7単元の一覧
├── plants.js                # 植物の問題データ
├── animals.js               # メダカ・人の問題データ
├── weather.js               # 天気の問題データ
├── river.js                 # 流れる水の問題データ
├── solutions.js             # 物のとけ方の問題データ
├── electromagnet.js         # 電磁石の問題データ
├── pendulum.js              # ふりこの問題データ
├── storage.js               # 進捗保存
├── gamification.js          # 発見・報酬
├── asset-rewards.js         # コレクション表示
├── extras.js                # 問題データの補助処理
├── labs/
│   ├── index.js
│   ├── lab-core.js
│   ├── plants-lab.js
│   ├── animals-lab.js
│   ├── weather-lab.js
│   ├── river-lab.js
│   ├── solutions-lab.js
│   ├── electromagnet-lab.js
│   ├── pendulum-lab.js
│   └── labs.css
├── simulators.js            # 互換用のLAB実行バンドル
├── lab-runtime.js           # LAB実行バンドル
└── README.md
~~~

現在の入口は index.html と app.js です。app.js には、問題画面とGitHub Pagesで動かすLABランタイムがまとめられています。labs フォルダには、単元別LABを管理するためのソースモジュールが置かれています。simulators.js と lab-runtime.js は互換用に残している実行バンドルで、index.html から直接は読み込んでいません。

LABを修正・追加するときは、catalog.js、対応する問題データ、labs フォルダ内のLABマニフェストと単元ファイル、app.js の実行バンドルを同じ内容に保つ必要があります。既存の問題判定・進捗保存を残したまま、LAB部分を単元ごとに拡張できる構成です。
