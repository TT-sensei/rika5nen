# 理科ラボ 5

小学5年生理科を「知識・実験準備・考察」の3段階で学ぶ、ブラウザ完結型の教材です。植物、メダカ・人、天気、流れる水、物のとけ方、電磁石の6単元を収録しています。

## 特徴

- タブレットで押しやすいレスポンシブUI
- 条件カードを「変える条件」「そろえる条件」に分類する実験準備ゲーム
- メダカ・人と天気では、目的に合う観察・観測項目を選ぶ準備ゲーム
- 実験結果から「言えること／言えないこと」を判断する考察問題
- 進捗、初回正解、間違えた条件カードを `localStorage` に保存
- 外部API、APIキー、サーバー、データベース、外部フォント不使用
- GitHub Pagesでそのまま公開可能

## 公開方法

リポジトリ直下にこのフォルダ内のファイルを置き、GitHubの Settings → Pages で `main` ブランチのルートを公開元に設定します。ビルド処理は不要です。

## 次の単元を追加する方法

1. `js/units/` に単元データファイルを追加する。
2. `index.html` でそのファイルを `app.js` より先に読み込む。
3. `catalog.js` の対象単元を `available: true` にする。
4. データを `knowledge / preparation / consideration` の3区分で登録する。

共通ロジックは `app.js` にまとめてあります。準備フェーズは、条件を「変える／そろえる」型と、必要な観察項目をすべて選ぶ型の2種類に対応しています。

## 教材内容の基準

- 文部科学省「小学校学習指導要領（平成29年告示）解説 理科編」
- 文部科学省「小学校理科の観察、実験の手引き」第5学年各内容
- 国立教育政策研究所「令和7年度 全国学力・学習状況調査 小学校理科 解説資料」

条件制御では、調べたい要因だけを変え、それ以外をそろえる考え方を全単元の共通パターンにしています。全6単元で、知識18題、実験・観察準備20題、考察30題を収録しています。
